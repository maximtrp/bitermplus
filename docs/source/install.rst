Installation
------------

Linux and Windows
~~~~~~~~~~~~~~~~~

Install *bitermplus* directly from PyPI:

.. code-block:: bash

    pip install bitermplus

For the latest development version:

.. code-block:: bash

    pip install git+https://github.com/maximtrp/bitermplus.git

Mac OS
~~~~~~

Install *bitermplus* directly from PyPI:

.. code-block:: bash

    pip install bitermplus

Requirements
~~~~~~~~~~~~

* cython
* numpy
* pandas
* scipy
* scikit-learn
* tqdm
